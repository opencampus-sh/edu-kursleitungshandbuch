# Start

Hier findet ihr die jeweils aktuellen Semestertermine und alles, was ihr für die Vorbereitung und Durchführung eures Kurses braucht. Was wann zu tun ist, seht ihr auf einen Blick in der [Semester-Checkliste](todos/semester-checkliste.md).

{% hint style="info" %}
**Neu seit dem Wintersemester 2026/27:** Die Prüfungsleistung ist immer ein Projekt, das präsentiert wird. Onlinekurse zählen nicht mehr als Leistungsnachweis (siehe [Projekte & Prüfungsleistungen](todos/tipps-zur-durchfuehrung-interner-projekte.md)).
{% endhint %}
